※ [해결됨] F4 입력 파라미터 전체 목록: 질문8 팀 답변("등에 해당하는 나머지 파라미터를 지금 다 정하자")으로, 원래 프로젝트 스펙(섹션13, Preset Parameter Model)에 정의된 전체 목록을 그대로 F4 입력 칸에 반영함(위 표 참고). 각 파라미터의 구체적 값 범위(min/max)는 이 문서의 범위를 넘어서는 데이터 사전 성격이라 별도 문서에서 다룰 수 있음 — 지금은 다루지 않는다(팀이 요청하면 새 문서로).

※ 참고(MVP 범위 밖): 05-policy.md 질문4에서 팀이 "나중에 커뮤니티도 생각 중이야. 프리셋 공유 커뮤니티 같은 거지."라고 답함 — 이는 02-workflow.md의 "모바일 APK"와 마찬가지로 향후 로드맵에 가까운 내용. 현재 F1~F9에는 영향 없음으로 처리하고, 커뮤니티 관련 결정은 이 문서 범위 밖으로 둔다.

※ [마무리 정리] F1 예외(페이지 로드 실패 등)는 팀에게 묻지 않고 그대로 [?]로 열어둔 채 문서를 마무리한다 — 근거: 정적 랜딩페이지라 실패 케이스의 비중이 낮고, 있다 해도 일반적인 웹 에러 페이지 수준이라 구현 시 자연스럽게 정해질 사항으로 판단.
